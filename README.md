### 🌍 Import Finance & Landed Cost

A custom Odoo workflow for managing import-related financial costs.

```text
Purchase Order
      ↓
Import Case
      ↓
Import Costs
      ↓
Payment Requests
      ↓
Cost Sheet
      ↓
Cost Allocation
      ↓
Landed Cost
      ↓
Inventory Valuation
      ↓
Final Product Cost
```

The workflow handles costs such as:

* Insurance
* Freight
* Customs
* LC-related costs
* Logistics costs
* Other import expenses

Costs can be allocated to imported products and integrated with inventory valuation and accounting.
